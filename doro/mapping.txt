# ─────────────────────────────────────────────────────────────
# doro 表情包映射表
#
# 格式：   emoji -> 表情包id        # 说明（# 之后是注释，随便写）
#   · 连字符用 -> 或 → 都行
#   · 一行可以写多个 emoji（空格／逗号／顿号分隔），它们都映射到同一张图
#   · 同一个表情包 id 可以出现在多行（多对一）
#   · 以 # 开头的行是注释
#
# 顺序：   就是优先级。一条回复里出现多个已映射 emoji 时，工具只补最靠前那张，
#          其余 emoji 照样会被摘掉但不再补图。想调优先级就调行顺序。
#
# 生效：   仅 QQ 私聊的短回复（≤3 行、≤200 字、不含代码块）会被替换；
#          微信、长回复、代码块一律原样不动。
#
# 写入：   在本项目根目录运行   python doro\apply-mapping.py
#              --dry-run   只检查、预览差异，不写入
#              --list      看线上有哪些表情包 id 可选（带场景说明）
#
# 注意：   左边必须写完整的一个 emoji。别写 ❤ 这种会被客户端补成 ❤️ 的半截，
#          也别写肤色修饰符或组合 emoji 的一部分——脚本会拦截。
# ─────────────────────────────────────────────────────────────
